            GaussView: Export for GaussView writes the currently selected full model (DNA + CaOx + waters) from the source PDB — default is the 5-row gel. Open the .pdb in GaussView to see bonds; use the .gjf to add H and submit. Files land in viewer/gaussview_exports/.
            Run in Gaussian still submits a small QM cluster (P / C1′ / N + nearby CaOx), not the full gel.
            Raman: preset Opt + Raman writes frequencies, IR, and Raman activities (Freq=Raman). Keep the cluster small (≲80 atoms). After the job, open the .log or .chk in GaussView → Results → Vibrations.
